"An interactive digital space showcasing photography, sound, and generative visual experiences."

What's inside:

* Photo ring & before/after views
* Filter by color or trip
* Live interactive audio & 3D lamp
* Dynamic index & signature

Tech Stack:

* Astro, GSAP, Web Audio API, Cloudflare Pages

Local Setup:

1. git clone 
2. npm install
3. npm run dev

Folder Structure:

* src/ (components, layouts, pages, styles)
* public/ (images, audio assets)
